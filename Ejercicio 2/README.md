# Sistema Museo

## Descripción

El sistema Museo es una aplicación desarrollada en Java con enfoque orientado a objetos (POO), cuyo objetivo es gestionar el catálogo de obras de arte, sus restauraciones, cesiones a otros museos y el control de usuarios dentro del sistema.

Este sistema permite:

- Gestionar el catálogo de obras (cuadros, esculturas y otros objetos)
- Registrar y consultar restauraciones
- Calcular el valor total del museo
- Gestionar la cesión de obras
- Autenticar usuarios
- Consultar obras disponibles

---

## Tecnologías utilizadas

- Java
- Programación Orientada a Objetos (POO)
- Buenas prácticas de programación
- Principios SOLID

---

## Programación Orientada a Objetos

- **Clase:** Estructura que define objetos (ej: Obra).
- **Objeto:** Instancia de una clase.
- **Encapsulamiento:** Uso de atributos privados y métodos públicos.
- **Abstracción:** Uso de clases abstractas como Obra.
- **Herencia:** Cuadro y Escultura heredan de Obra.
- **Polimorfismo:** Uso de diferentes tipos de obras mediante una misma referencia.

---

## Principios SOLID

- **S (Single Responsibility):** Cada clase tiene una única responsabilidad  
- **O (Open/Closed):** El sistema permite extensión sin modificar código existente  
- **L (Liskov Substitution):** Las subclases pueden sustituir a la clase base  
- **I (Interface Segregation):** Uso de interfaces específicas como Autenticable  
- **D (Dependency Inversion):** Dependencia de abstracciones en servicios
